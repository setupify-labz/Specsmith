# SEO Strategy

## In scope
- Public marketing pages: `/`, `/about`
- Public utility / discovery pages: `/builder`, `/prebuilts`, `/compare`, `/build`
- Shared navigation, footer, and HTML shell used by those routes

## Out of scope
- Authenticated account surfaces: `/dashboard`, `/settings`
- Auth entry pages: `/login`, `/signup`
- Unused backend packages unless they serve public FrameForge pages

## Target audience
- PC gamers researching components and expected game performance
- First-time and intermediate PC builders comparing parts and prebuilts

## Primary keywords
- PC builder
- FPS estimator
- gaming PC builder
- prebuilt gaming PC
- GPU CPU comparison
- PC build comparison

## Notes
- FrameForge is currently a Vite + React Router SPA with a shared `index.html` shell.
- Public routes rely on client-side rendering for their content.
