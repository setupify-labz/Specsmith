How it works:
  - Encode entire build as base64 JSON string
  - Share URL format: frameforge.gg/build?b={base64string}
  - Visiting a share URL pre-loads that exact build into 
    the builder automatically
  - No server needed — all state in URL param

Share button:
  - In build summary panel + on dashboard build cards
  - Clicking copies URL to clipboard
  - Button text changes: "Share Build" → "Link Copied!" 
    with checkmark icon (resets after 2.5s)
  - Also shows QR code in a modal (use qrcode.react library)

Shared build page:
  - When visiting /build?b=... as a guest:
    - Show read-only build summary at top
    - FPS estimates for all 20 games
    - Total price
    - "Load this build" button → opens in builder
    - "Save to my account" button → prompts login/signup

    - og:title: "[Build Name] — FrameForge"
    - og:description: "[GPU] + [CPU] | Est. [X] FPS in

ADDITION 4 — BOTTLENECK CHECKER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Location: Appears in build summary panel below part list,
visible as soon as both GPU and CPU are selected.

Algorithm:
  gpu_score = gpu.benchmark_score
  cpu_score = cpu.benchmark_score
  ratio = gpu_score / cpu_score

  if ratio > 1.4:
    bottleneck = "CPU"
    severity = ratio > 1.7 ? "severe" : "moderate"
    pct = Math.round((ratio - 1) * 100)
    message = "Your CPU is bottlenecking your GPU by ~{pct}%.
               Your GPU is being held back. Consider upgrading
               to a faster CPU to unlock full performance."

  else if ratio < 0.72:
    bottleneck = "GPU"
    severity = ratio < 0.55 ? "severe" : "moderate"
    pct = Math.round((1 - ratio) * 100)
    message = "Your GPU is bottlenecking your CPU by ~{pct}%.
               Your CPU is faster than your GPU can keep up 
               with. Consider a stronger GPU for this build."

  else:
    bottleneck = "none"
    message = "Great balance! Your CPU and GPU are 
               well-matched for maximum performance."

UI display:
  - Card with title "Bottleneck Analysis"
  - Horizontal balance bar:
    - Left label: CPU score
    - Right label: GPU score
    - Bar fills from center — purple for CPU side, 
      cyan for GPU side
    - Ideal zone marker in center (small white tick)
    - Bar animates on load: grows from center outward (600ms)
  - Below bar: colored status badge
    - Green "Balanced" if no bottleneck
    - Amber "Moderate Bottleneck" if moderate
    - Red "Severe Bottleneck" if severe
  - Message text in muted color below badge
  - "Fix it" suggestion button:
    - If CPU bottleneck: "Upgrade CPU →" scrolls to CPU 
      selector and highlights top 3 matching CPUs
    - If GPU bottleneck: "Upgrade GPU →" scrolls to GPU 
      selector and highlights top 3 matching GPUs
    - Highlighted cards get a glowing purple border 
      + "Recommended" badge for 3 seconds
