━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Throw out the old tier-based formula entirely.
Use this lookup-based system instead.

Each GPU has a gpu_multiplier value (not tier).
Each CPU has a cpu_multiplier value (not tier).
Base FPS values are set for a "reference GPU" 
(RTX 4090 = 1.0 multiplier).

FORMULA:
  raw = game.base_fps[resolution][preset] × gpu.multiplier
  estimated = raw × cpu.multiplier
  fps_min = Math.round(estimated × 0.92)
  fps_max = Math.round(estimated × 1.08)
  display = Math.round(estimated)
  Cap at 999. Floor at 1.
